## 基本概念

### Mod 键
本配置使用 **Super 键**（Windows 徽标键 ⊞ / Apple Command 键 ⌘）作为主修饰键，文档中简称为 `Mod`。

### 窗口布局模式
- **Tabbed（标签式）**: 默认布局，窗口以标签形式堆叠
- **Stacked（堆叠式）**: 窗口垂直堆叠显示标题栏
- **Tiled（平铺式）**: 窗口水平或垂直分割平铺

### 工作区
i3 提供 10 个独立工作区（编号 1-10），每个工作区可运行不同应用。

## 快捷键说明

### 应用启动

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Mod + Enter` | 打开终端 | 启动 Termite 终端 |
| `Mod + F3` | 打开浏览器 | 启动 Google Chrome |
| `Mod + F5` | 打开文件管理器 | 启动 Thunar |
| `Print` | 截图 | Flameshot 延迟 200ms 截图 |
| `Mod + Shift + Print` | 截图设置 | 打开 Flameshot 配置 |
| `Mod + Shift + Ctrl + M` | 音频混音器 | 启动 alsamixer |

### 服务控制

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Mod + Tab` | 窗口切换器 | Rofi 窗口选择器 |
| `Mod + D` | 应用启动器 | Rofi 应用菜单（3列） |
| `Mod + Shift + D` | 命令运行器 | Rofi 命令执行 |
| `Mod + Shift + A` | 系统菜单 | 系统控制菜单 |
| `Mod + Shift + P` | 电源菜单 | 关机/重启/注销等 |
| `Mod + G` | 文档搜索 | Rofi-Zeal 搜索 Zeal/Man 文档 |
| `Mod + Ctrl + M` | 媒体播放器 | Rofi 多媒体控制 |

### 窗口管理

#### 焦点移动
| 快捷键 | 功能 |
|--------|------|
| `Mod + ←/↓/↑/→` | 移动焦点到左/下/上/右窗口 |
| `Mod + Space` | 焦点切换到浮动窗口 |

#### 窗口移动
| 快捷键 | 功能 |
|--------|------|
| `Mod + Shift + ←/↓/↑/→` | 移动当前窗口到左/下/上/右 |
| `鼠标 + Mod` | 拖动浮动窗口 |

#### 窗口调整
| 快捷键 | 功能 |
|--------|------|
| `Mod + R` | 进入调整大小模式 |
| `Mod + Ctrl + Shift + ←/→/↑/↓` | 快速调整窗口大小（10px） |

**调整大小模式中**:
- `←/→/↑/↓` 或 `H/J/K/L`: 调整窗口大小
- `Enter` 或 `Esc`: 退出调整模式

#### 窗口状态
| 快捷键 | 功能 |
|--------|------|
| `Mod + F` | 全屏切换 |
| `Mod + Shift + Space` | 浮动/平铺切换 |
| `Mod + Shift + S` | 粘滞窗口切换 |
| `Mod + B` | 边框类型切换 |
| `Alt + F4` | 关闭当前窗口 |

#### 暂存窗口（Scratchpad）
| 快捷键 | 功能 |
|--------|------|
| `Mod + Shift + -` | 将窗口移到暂存区 |
| `Mod + -` | 显示/隐藏暂存窗口 |

### 工作区管理

#### 切换工作区
| 快捷键 | 功能 | 智能启动 |
|--------|------|----------|
| `Mod + 1` | 工作区 1 | Termite 终端 |
| `Mod + 2` | 工作区 2 | Ghostty 终端 |
| `Mod + 3` | 工作区 3 | Google Chrome |
| `Mod + 4-9` | 工作区 4-9 | 无 |
| `Mod + 0` | 工作区 10 | V2RayN |

#### 工作区导航
| 快捷键 | 功能 |
|--------|------|
| `Mod + Ctrl + ←` | 切换到上一个工作区 |
| `Mod + Ctrl + →` | 切换到下一个工作区 |

#### 移动窗口到工作区
| 快捷键 | 功能 |
|--------|------|
| `Mod + Ctrl + 1-0` | 移动窗口到指定工作区（不跟随） |
| `Mod + Shift + 1-0` | 移动窗口到指定工作区（跟随） |

### 布局切换

| 快捷键 | 功能 |
|--------|------|
| `Mod + S` | 堆叠布局（Stacking） |
| `Mod + W` | 标签布局（Tabbed） |
| `Mod + E` | 平铺布局切换（水平/垂直） |
| `Mod + X` | 所有布局轮回切换 |
| `Mod + Ctrl + H` | 水平分割视窗 |
| `Mod + Ctrl + V` | 垂直分割视窗 |

### 系统控制

| 快捷键 | 功能 |
|--------|------|
| `Mod + Shift + C` | 重载 i3 配置 |
| `Mod + Shift + R` | 重启 i3wm |
| `Mod + Ctrl + X` | xkill（强制关闭窗口） |
| `Mod + Shift + B` | 电子书选择器 |

| 工作区 | 应用 | 布局 |

| **2** | 微信、Ghostty | Tabbed |

| **4** | VLC 播放器 | Tabbed |
| **5** | （未分配） | - |
| **6** | Zeal 文档查看器 | Tabbed |
| **7** | VS Code、Emacs | Tabbed |
| **8-9** | （未分配） | - |

**浮动窗口规则**:
- Arandr（显示器设置）
- 电源管理设置
- 网络连接编辑器
- 所有弹出窗口和对话框

## i3-gaps 间距调整

### 当前默认设置
- **内间距（inner）**: 8px
- **外间距（outer）**: 0px
- **智能间距**: 开启（单窗口时不显示间距）
- **智能边框**: 开启（单窗口时不显示边框）

### 动态调整间距
1. 按 `Mod + Shift + G` 进入间距模式
2. 按 `O`（外间距）或 `I`（内间距）
3. 使用以下键调整:
   - `+`: 增加 1px
   - `-`: 减少 1px
   - `0`: 重置为 0
   - `Shift + +/-/0`: 应用到所有工作区
4. `Enter` 或 `Esc` 退出

## 多显示器设置

按 `Mod + Shift + M` 进入显示器模式，然后:
- `S`: 单屏模式
- `D`: 双屏模式

脚本位置: `~/.config/i3/screenlayout/`

## 剪贴板管理

本配置集成 **clipcat** 剪贴板管理器：

| 快捷键 | 功能 |
|--------|------|
| `Mod + P` | 打开剪贴板历史（插入） |
| `Mod + O` | 打开剪贴板历史（删除） |

clipcat 守护进程随 i3 自动启动。

## 依赖软件

### 必需
- **i3-gaps**: i3wm 间距增强版
- **polybar**: 状态栏（替代 i3bar）
- **rofi**: 应用/窗口启动器
- **termite** / **ghostty**: 终端模拟器
- **clipcat**: 剪贴板管理器

### 推荐
- **thunar**: 文件管理器
- **flameshot**: 截图工具
- **google-chrome-stable**: 浏览器
- **feh**: 壁纸设置
- **xcompmgr** / **picom**: 合成器（阴影/透明）
- **freetype-infinality**: 字体渲染优化
- **zeal**: 离线文档查看器
- **v2rayn**: 代理工具

### 字体
- **DejaVu Sans Mono**: 等宽编程字体
- **Font Awesome**: 图标字体

## 故障排查

### 配置不生效
```bash
# 检查配置语法
i3-msg -t get_config

# 重载配置
Mod + Shift + C

# 如需完全重启
Mod + Shift + R
```

### Polybar 未启动
```bash
# 手动启动
~/.config/polybar/launch.sh

# 查看日志
journalctl --user -u polybar
```

### 快捷键冲突
检查 `~/.config/i3/config` 文件中的 `bindsym` 定义，确保无重复。

## 自定义建议

### 修改 Mod 键
如需使用 Alt 键作为 Mod:
```
set $mod Mod1
```

### 添加新的工作区绑定
```
bindsym $mod+F1 workspace "工作区名称"
```

### 修改默认终端
替换 `exec termite` 为你喜欢的终端（如 `alacritty`, `kitty`）。

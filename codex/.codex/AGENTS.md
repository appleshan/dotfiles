# AGENTS.md

## 🌍 语言设置
**重要：Claude 助手必须始终使用中文回复所有问题和对话。**

无论用户使用什么语言提问，回复都必须是中文，包括：
- 代码注释和说明
- 技术文档和解释
- 问题分析和解决方案
- 错误信息和调试建议

## 🚀 环境运行说明

### 重要提醒
**用户会自行运行开发环境，无需 Claude 助手协助启动或管理服务。**

用户负责：
- 启动后端服务
- 启动前端开发服务器
- 管理连接
- 管理缓存连接
- 配置环境变量

Claude 助手的职责：
- 提供代码编写和修改建议
- 解答技术问题
- 协助调试代码问题
- 提供最佳实践指导
- 可以在需要时适当的增加日志来排查问题

**记住：所有回复和交流都必须使用中文！**
